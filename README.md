# 🍔 Fast Food Landing Page

A modern **Fast Food Restaurant Landing Page** built with HTML and CSS.
The project focuses on creating an attractive restaurant website with food items, restaurant information, customer testimonials, and other essential sections.

## 🌐 Live Demo

**Visit the website:**
https://fast-food-landing-page-kappa.vercel.app/

## ✨ Sections

* 🏠 Hero / Home Section
* 🍕 Best Food Maker Section
* 🍔 Food Menu
* 📊 Restaurant Statistics
* 🤝 Franchise Section
* ⭐ Customer Testimonials
* 📩 Newsletter Section
* 📍 Restaurant Location
* 🔗 Footer

## 🛠️ Technologies

* HTML5
* CSS3

## 📱 Responsive Status

> ⚠️ **Note:** This project is currently **not responsive** and is mainly designed for desktop screens. Responsive design will be added in a future update.
